# Java Portfolio Project: Hospital Management System

This is a **real-world Java project** you can showcase in your portfolio. It models the basic operations of a hospital:

- Manage doctors
- Manage patients
- Schedule appointments

## Why this is a good portfolio project

Recruiters and interviewers like projects that solve practical problems. Hospital/School/Inventory systems demonstrate:

- OOP concepts (encapsulation, composition)
- Collections and data handling
- Service-layer design
- Expandability toward real production stacks (Spring Boot, JDBC, REST)

## Tech Stack

- Java 17
- Maven

## Project Structure

```text
src/main/java/com/portfolio/hospital
├── HospitalManagementApp.java
├── model
│   ├── Appointment.java
│   ├── Doctor.java
│   └── Patient.java
└── service
    └── HospitalService.java
```

## Run the project

```bash
mvn -q compile exec:java
```

## Suggested upgrades for your next commits

1. Add database persistence (MySQL/PostgreSQL + JDBC).
2. Convert to Spring Boot REST API.
3. Add role-based users (Admin/Doctor/Receptionist).
4. Add billing and pharmacy modules.
5. Add unit tests with JUnit.

## Alternative portfolio themes

If you want similar projects, you can build:

- School Management System
- Library Management System
- Blood Bank Management System
- Student Attendance Tracker

All of these are highly interview-friendly for Java fresher portfolios.
